# Code of Conduct

## Our standard

We are committed to making participation in HealthScan welcoming and
respectful. Contributors must communicate professionally and in good faith.
Harassment, discrimination, personal attacks, doxxing, sexualized conduct,
and deliberately disruptive behavior are not acceptable.

## Scope and enforcement

This code applies to project spaces and public interactions where someone
represents the project. Maintainers may remove comments, edit or close issues,
or restrict participation when conduct violates this standard.

Report concerns privately to the repository maintainers through the contact
method listed in the repository profile. Please do not include sensitive health
data in a report.
