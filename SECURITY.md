# Security Policy

## Supported versions

This project is currently maintained on the default branch only. There are no
guaranteed security fixes for older snapshots.

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. Use GitHub's private
security advisory feature for this repository when available. Otherwise,
contact the maintainers privately through the contact details in the GitHub
repository profile.

Include a clear description, affected file or version, reproduction steps,
potential impact, and any suggested mitigation. Remove personal data,
credentials, camera frames, and other sensitive information before sending a
report.

Please allow maintainers reasonable time to investigate and release a fix
before publicly disclosing the issue.
